# EstateX - Real Estate React Website

A complete, responsive real-estate frontend built with React + Vite.

## Included pages

- Home
- Property Listing
- Search and Filters
- Property Details
- Agents
- Agent Details
- Login
- Sign Up
- Contact

## Tech

- React
- Vite
- React Router DOM
- Lucide React
- Responsive CSS

## Run

Open the project folder in VS Code and run:

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

## Important

This is a frontend project. Login, signup and contact forms are demo interactions only; no backend/database is connected.

All JSX files explicitly import React, and `vite.config.js` includes the React plugin to avoid `React is not defined` / JSX transform issues.
